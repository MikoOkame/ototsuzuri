# 宣伝動画の書き出し

同じ手順で何度でも撮り直せる（オルゴールや箱を作り直したあとも、これを流し直すだけ）。

## 準備（最初の1回）
```
cd tools/promo
npm install          # playwright-core と three 0.160
```
Chromium の場所は環境変数 `CHROME` で指定する（既定は `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`）。ffmpeg も要る。

## 撮る
```
node render.mjs full   # 一本につながった宣伝動画（音つき）
node render.mjs share  # シェアカードの1枚絵
node render.mjs        # 全部
```
出力は `tools/promo/out/promo_full.mp4`（音つき）。1920×1080、30fps、H.264。

## 設定（shots.json）
- 画角は、制作版を `?debug` で開き、カメラを動かして「画角をコピー」で出る `{"pos":[…],"target":[…],"fov":…}` をそのまま貼る（fov は縦の画角・度）。
- 画角は `cams` に名前（A・B・C…）を付けて置く。
- `keys` は `[秒, 画角の名前]` の並び。同じ名前が続く間はそこに留まり、違う名前の間を滑らかに（端でゆっくり）移る。例：`[[0,"A"],[1,"A"],[3.5,"B"],[5.5,"B"],[8.5,"C"]]` は、A に1秒 → 2.5秒で B へ → B に2秒 → 3秒で C へ → 最後まで C。
- `keys` の代わりに、`camA`（始まり）・`camB`（終わり）・`move`（移る秒数）でも書ける。`camB` が無ければ固定。`camA` などには名前も、数値の画角もそのまま書ける。
- `dayKeys` は `[秒, 時刻]` の並び。時刻の流れに緩急を付ける（キーの間は、速さが急に変わらないように滑らかにつなぐ）。1 を越えると翌日。鳥は普段と同じ規則で、時刻で出入りする（手すりの2羽は 0.80 前後で帰り、0.976・0.993 に戻る）。飛ぶ動き自体は実時間で 3〜4 秒かかるので、その間は時刻をゆっくり流す。
- `birdArrive` は鳥ごと（手すり左・手すり右・窓台）に飛来を始める秒。指定した鳥は最初は居らず、その秒ちょうどに飛んでくる。
- `dayT` は撮影 0 秒の時刻（0＝真夜中、0.42＝昼、0.62＝夕方）。`daySeconds` を書くと、撮影中だけ一日をその秒数で回す（準備の warmup 中は時刻を止める）。B（画角 C に固定）は 0.42 から10秒：1.8〜3.2秒で夕方の窓明かりが灯り、4秒前後が夜、5.5秒前後で夜明け。
- `track` は曲の id。`play` で曲を流し（オルゴールが回り、鳥が歌う）、`audio` で音を書き出して合成する。
- `warmup` 秒だけ、曲を止めたまま先に進めて鳥を落ち着かせてから撮り始める。曲は撮影の 0 秒で頭から始まる。
- 1枚絵（シェアカードなど）は `still: true`。`width`・`height` で大きさ、`dayT` を配列にすると時刻ごとに1枚ずつ、`at` 秒だけ曲を流したところを撮る。`node render.mjs share` → `out/share_0.42.png` など（画角 D、1200×630、昼・夕方・夜）。
- `seed` で乱数を固定する（鳥の動き・顔ぶれ・音の残響）。`birds` で出す鳥（手すり左・右・窓台）。

## 仕組み（src/orgel_dev.html の「撮影モード」節）
- `?capture` で開くと、実時間のループを止め、1コマ = 1/30 秒ずつ進めて描く。重い環境でも、動きと音はずれない。
- 録画中は UI（タイトル・再生パネル・ヒント・曲一覧ボタン・デバッグ表示）を出さない。紙目と周辺減光は絵の一部なので残す。
- 音：撮影中は鳴らさず、曲の位置だけをコマに合わせて進める。書き出しでは、曲の全パートを同じ時間軸でオフライン合成する。ピンが櫛歯を弾くコマと、その音の発音時刻は 1 コマ（33ms）以内で一致する。鳥の声は撮影中に起きた時刻を記録し、同じ時刻に鳴らす。
