## 2. 書き出しの形式

- 1080×1920、30fps、H.264 の mp4、音つき（AAC）。
- 長さは約 100 秒（§4）。
- **X 側の制限は確かめていない。** 長さの上限、解像度、ファイルの大きさ、タイムラインで音が出るかを、撮る前に検索して確かめる。上限が 100 秒より短ければ、曲を縮めるか構成を変える。
- 撮影時間の見込み：約 3,000 コマ × 約 2 秒 ＝ **約 1 時間 40 分**。前の実測（1920×1080 で 1 コマ約 2 秒）から出した値で、縦長でも画素の数は同じ。

## 3. UI を映す

### 3.1 映すもの
- 普段の iPhone の縦画面と同じ UI：タイトル「音綴り」、曲一覧ボタン、再生パネル（曲名・副題・前へ・再生・次へ・全曲・🗝・声・音量）。
- 撮影用に足すもの：**タップの印**。指で押した所に出る、小さな波紋の輪。押したことが見て分かるように、0.4 秒ほどで広がって消える。
- 映さないもの：デバッグ表示、ヒント（「ドラッグで回せます」など）。

### 3.2 作り
- 今の撮影モード（`?capture`）は、`body.capturing` で UI を隠している。これに **`ui: true`** の設定を足し、true のときは隠さない。
- UI の表示は、撮影のコマの時計に合わせて動くようにする：再生ボタンの ▶/⏸、曲名、🗝 の残り時間。
- **文字の書体を必ず読み込む**（Zen Maru Gothic）。確認用の撮影では外部の書体を切っていたので、本番では読み込まれるまで待ってから撮り始める。
- `deviceScaleFactor` は 1（1080×1920 をそのまま撮る）。UI の大きさは iPhone の画面幅 390px を基準に作ってあるので、`viewport` を 390×693 にして `deviceScaleFactor` を約 2.77 にするやり方も考えられる（どちらが iPhone の見た目に近いかは、試し撮りで比べる）。

### 3.3 操作を台本にする
- 撮影の設定に、何秒に何を押すかを書く：

```json
"actions": [
  [0.6, "windHold", 1.8],
  [3.0, "tap", "#playBtn"]
]
```

- `windHold`：巻き鍵を指定の秒数だけ長押しする。カチッの音と鍵の回転を出し、🗝 の数字を増やす。
- `tap`：指定の UI を押す。タップの印を出し、そのボタンの動作をさせる。
- 音はオフラインの合成に入れる。巻く音（`windPattern`・`windClick`）は、もともと音のコンテキストを引数に取る作りになっているので、そのまま書き出しに使える。

## 4. 構成（案）

| 時間 | 画 | 音 | UI |
|---|---|---|---|
| 0〜0.6 秒 | 巻き鍵の寄り。曲は止まっている | 無音（環境音があれば） | 再生パネルは ▶ |
| 0.6〜2.4 秒 | 鍵を長押しして巻く。鍵が回る | ラチェットのカチッが詰まっていく。最後に止まる手応え | 🗝 の分数が増える |
| 2.4〜4 秒 | オルゴールを覗く画角へ引く | — | 再生ボタンにタップの印 → ⏸ |
| 4〜98.5 秒 | おもいでのワルツを 1 周。カメラは 3〜4 か所をゆっくり移る。途中で鳥が飛んできて歌う | 曲（94.5 秒） | 曲名「おもいでのワルツ〜とべないころの、空のゆめ〜」 |
| 98.5〜101 秒 | 締め（§9 の 3） | — | — |

- 始まりの数秒は、タイムラインで指を止めてもらう所。画が動いていて、何のアプリかが分かるものにする。
- 曲の頭は、撮影の 4 秒ちょうどにそろえる（今の仕組みは 0 秒に曲の頭が来るので、曲を始める時刻を指定できるようにする）。

### 4.1 カメラ（案）
- 画角はユーザーが決める（制作版 `?debug` を**縦長の画面**で開き、「画角をコピー」で取る）。
  - 前の動画の画角は横長用なので、そのままでは使えない。
- 割り付けの例：
  1. 鍵の寄り
  2. オルゴール全体
  3. 鳥のアップ
  4. 窓の外へ引く
  5. 最後は全体（シェアカードの画角 D に近いもの）
- 曲の区切り（フレーズの変わり目）でカメラを移すと、曲と画がそろって見える。区切りの秒は、譜面から出して一覧にする。

### 4.2 時間帯（案）
- 夕方から夜へ流す。曲の後半で窓明かりが灯り、最後は夜。
- `dayKeys` で緩急を付ける。鳥が帰る時刻（0.80 前後）を曲の途中に入れるかどうかは、画を見て決める。

### 4.3 鳥（案）
- 曲の前半で 1〜2 羽が飛んでくる（`birdArrive`）。窓台の鳥は着地したらすぐ歌う（`singOnLand`）。
- 鳥の顔ぶれはユーザーが決める。今の `full` は kurumi・momo・sora。

## 6. 設定の形（`shots.json` に足す）

```json
"x": {
  "_説明": "X 用の縦長動画。UI を映し、鍵を巻いてから おもいでのワルツを 1 周",
  "width": 1080, "height": 1920, "fps": 30,
  "seconds": 101,
  "ui": true,
  "track": "（おもいでのワルツの id）",
  "play": true, "audio": true,
  "trackStart": 4.0,
  "actions": [[0.6, "windHold", 1.8], [3.0, "tap", "#playBtn"]],
  "keys": [],
  "dayKeys": [],
  "birdArrive": [],
  "singOnLand": ["sora"],
  "ending": "（spring か fade。§9 の 3）"
}
```

`ui`・`trackStart`・`actions`・`ending` が新しく足す項目。ほかは今の仕組みのまま使う。

## 8. 確かめ方

1. 小さい大きさ（270×480）で全体を撮り、構成と秒の割り付けを見る。
2. 1080×1920 で数か所を 1 枚絵で撮り、UI の文字の大きさと見た目を iPhone の画面と比べる。
3. 本番を撮る。巻く音とカチッ、タップと再生、曲の頭がずれていないかを確かめる。
4. X に上げる前に、手元のスマホで縦に再生して見る。
