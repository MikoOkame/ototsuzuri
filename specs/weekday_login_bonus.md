# 曜日ログインボーナス 仕様書（下書き）

対象：バーチャル個展会場ゲーム（仮）
作成：2026-10-09（音綴りの作りを前提にした下書き。未決定の所は §12 にまとめた）

---

## 1. 概要

- ゲームを開いた **曜日ごとに違う髪飾り** を1日1回もらえる。
- 髪飾りは鳥（登場キャラクター）の頭に付けられる。
- **7種類（月〜日）を全部集めると王冠** がもらえる。
- サーバーは使わない。進み具合はブラウザに保存する（GitHub Pages などの静的な公開で動く）。

---

## 2. 用語

| 用語 | 意味 |
|---|---|
| 髪飾り | 曜日ごとの報酬。全7種 |
| 王冠 | 7種を揃えたときの特別な報酬。1つだけ |
| 受け取り | その日の髪飾りを手に入れること。1日1回 |
| 1日の区切り | 「次の日」に切り替わる時刻（§4.1） |
| ロケータ | 髪飾りを付ける位置と向きを決める、頭のジョイントの子の空ノード |
| 装着 | 手に入れた髪飾り（または王冠）を鳥に付けること |

---

## 3. 遊びの流れ

1. ゲームを開く。
2. 今日まだ受け取っていなければ、**受け取りの演出**（§7.1）が出て、今日の曜日の髪飾りが手に入る。
3. すでに持っている曜日なら、演出は「今日はもう持っている」旨にとどめる（§4.3）。
4. 7種目を手に入れた瞬間、続けて **王冠の演出** が出て、王冠が手に入る。
5. **コレクション画面**（§7.2）で、集めた髪飾りと王冠を見られ、鳥に付け外しできる。

---

## 4. 受け取りの決まり

### 4.1 1日の区切り
- 端末の時計（その端末の時間帯）で判定する。
- 区切りの時刻は `DAY_ROLLOVER_HOUR`（既定 **0時**。4時などにも変えられるようにしておく）。
- 区切り前の時刻は前日として扱う（例：区切りが4時なら、火曜3時台は「月曜」）。

### 4.2 1日1回
- 「受け取った日付」（区切りを考えた日付。例 `2026-10-09`）を保存し、今日の日付と同じなら受け取らない。
- 判定するのは、開いたとき・画面に戻ってきたとき（`visibilitychange`）・開きっぱなしで日付をまたいだとき（1分ごとの確認で十分）。

### 4.3 曜日と報酬

| 曜日 | 髪飾り（仮） | id |
|---|---|---|
| 月 | （未定） | `acc_mon` |
| 火 | （未定） | `acc_tue` |
| 水 | （未定） | `acc_wed` |
| 木 | （未定） | `acc_thu` |
| 金 | （未定） | `acc_fri` |
| 土 | （未定） | `acc_sat` |
| 日 | （未定） | `acc_sun` |
| 7種揃ったとき | 王冠 | `crown` |

- 既に持っている曜日に開いた場合：新しくは何も増えない（重ねて持つ仕組みは作らない。案は §12）。
- 受け損ねた曜日は、次の週の同じ曜日に開けばもらえる。救済（取り損ねを補う仕組み）は作らない（案は §12）。
- 王冠は7種が揃った時点で一度だけ与える。

### 4.4 時計を戻したとき
- 今日の日付が「最後に受け取った日付」より前なら、受け取りの判定をしない（巻き戻しで何度も受け取れないようにする）。
- 時計を進めて先の曜日をもらうことは防げない（§9）。

## 5. 装着

### 5.1 ロケータ（Maya で作る）
- 鳥のモデルの **頭のジョイント（`head`）の子** にロケータを置く。名前は `loc_hair`。
  - 今の鳥モデル（音綴りの `MyBird_v1.1`）の `head` には子が無いので、足して書き出し直す。
- ロケータの位置＝髪飾りの付け根、向き＝髪飾りの正面（+Z）と上（+Y）。
- glTF（glb）で書き出すと空のノードとして残り、コードから名前で見つけられる。
- 頭のジョイントの子なので、歌う・首を振る・飛ぶなどの動きにそのまま付いてくる。鳥ごとの大きさの違い（例：1.18 倍の鳥）にも一緒に拡大縮小される。

### 5.2 髪飾り・王冠のモデル
- 1種ずつ別の glb。ファイル名は id と同じ（`acc_mon.glb` … `crown.glb`）。
- 原点＝付け根（ロケータに重なる点）。単位は m、鳥の大きさ1倍のときの寸法で作る。
- 正面 +Z、上 +Y（ロケータと揃える）。
- 色はテクスチャか頂点色、またはマテリアルの色。読み込み時に、鳥と同じトゥーンの陰影と輪郭線に変換する。
- 光らせたいもの（王冠など）は、発光の色を設定しておけばそのまま使う。
- 目安：1つ 1,000 三角形以内、テクスチャ 512px 以内（スマホで軽く保つため）。

### 5.3 付ける対象（未決定。§12）
- 案A：全員に同じ飾りを付ける。
- 案B：付ける鳥と飾りの組を選ぶ（鳥ごとに保存）。
- 案C：お気に入りの1羽だけに付ける。

### 5.4 決まり
- 1羽に付けられる飾りは1つ（髪飾りか王冠）。
- 付けていない状態も選べる。

## 6. コード側の仕組み（参考）

```js
// 鳥の読み込み後
const loc = birdModel.getObjectByName('loc_hair');
function equip(bird, id){
  if(bird.acc){ bird.loc.remove(bird.acc); bird.acc = null; }
  if(!id) return;
  const src = accCache[id];                 // 読み込み済みの髪飾り（トゥーン変換済み）
  bird.acc = src.clone(); bird.loc.add(bird.acc);
}
// 1日の区切りを考えた日付と曜日
function gameDay(now = new Date()){
  const d = new Date(now.getTime() - DAY_ROLLOVER_HOUR*3600e3);
  return { key: d.toLocaleDateString('sv-SE'), dow: d.getDay() };   // 'YYYY-MM-DD'、0=日〜6=土
}
```

- `toLocaleDateString('sv-SE')` は端末の時間帯で `YYYY-MM-DD` を返す（UTC にしない）。
- 開発版だけ `?today=2026-10-12` で日付を上書きできるようにする（§10）。

## 7. 画面

### 7.1 受け取りの演出
- 開いた直後、ゲームの表示が落ち着いてから出す（読み込み中には出さない）。
- 内容：今日の曜日・髪飾りの絵と名前・「受け取る」ボタン（押して閉じる）。
- 7種目のときは、続けて王冠の演出。
- 演出の間に、鳥がその飾りを付けて見せると分かりやすい（任意）。

### 7.2 コレクション画面
- 月〜日の7枠＋王冠の1枠。持っていない枠は影（シルエット）で見せる。
- 持っている飾りを押すと、付ける鳥を選んで付けられる（§5.3 の案による）。
- 「外す」ボタン。
- 開く場所：再生パネルか画面の端のボタン（手描き UI に合わせる）。

### 7.3 表示しないとき
- 撮影モード（宣伝動画）では演出を出さない。装着は撮影の設定で指定できるようにする。

## 8. 保存

- 保存先：`localStorage`。キー `kotengame.loginBonus`（ゲーム名が決まったら変える）。
- 中身（JSON）：

```json
{
  "v": 1,
  "owned": { "acc_mon": "2026-10-12", "acc_tue": null, "acc_wed": null, "acc_thu": null,
             "acc_fri": null, "acc_sat": null, "acc_sun": null, "crown": null },
  "lastClaim": "2026-10-12",
  "equipped": { "all": "acc_mon" }
}
```

  - `owned`：手に入れた日付（まだなら null）。
  - `lastClaim`：最後に受け取った日付（1日1回と巻き戻しの判定に使う）。
  - `equipped`：付けている飾り。§5.3 の案に合わせて形を決める（案B なら鳥の id ごと）。
  - `v`：形を変えたときに読み替えるための版番号。
- 読み書きは必ず try で包む（プライベートブラウズなどで保存できない環境がある）。保存できないときも遊べるようにし、進み具合はその回だけにする。

## 9. 制約と注意

- **端末ごとに別々**：iPhone で集めた分は PC に引き継がれない。
- **消えることがある**：ブラウザのデータを消すと消える。iPhone の Safari は、しばらく訪れないサイトの保存データを消す仕組みがあると記憶している（7日が目安。ホーム画面に追加した Web アプリは対象外のはず）。**作る前に最新の仕様を調べる。** 毎日開く前提の仕組みなので影響が大きい。
- **時計を進めれば早く揃う**：サーバーが無いので防げない。遊びの範囲として許す。防ぐなら、サーバーとアカウントが要る。
- **時間帯**：海外へ移動すると曜日の切り替わりがずれるが、気にしない。

## 10. 確かめ方（開発版）

- `?today=YYYY-MM-DD`：今日の日付を上書きする（曜日ごとの受け取り、7種目、巻き戻しを試す）。
- `?lbreset`：保存を消す。
- デバッグ表示に、持っている飾り・最後に受け取った日付・今日の判定（受け取れる／済み／巻き戻し）を出す。
- 確認項目：
  1. 初めて開く → 今日の曜日の飾りがもらえる
  2. 同じ日に開き直す → 何も起きない
  3. 区切りの時刻の前後で、曜日が正しく切り替わる
  4. 7種目 → 王冠の演出が続けて出る。8日目以降に王冠が重ねて出ない
  5. 時計を戻す → もらえない
  6. 保存できない環境 → エラーにならず遊べる
  7. 飾りが歌・首振り・飛行に付いてくる。大きさの違う鳥でもずれない
